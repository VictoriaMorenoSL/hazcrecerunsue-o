# Haz crecer un sueño

Sitio web de **Enderezando Curvas A.C.** para comunicar el impacto de los donativos, el crecimiento del bosque de los sueños y las formas de participación para personas y empresas.

## Ver el proyecto en la web

### [Abrir Haz crecer un sueño](https://victoriamorenosl.github.io/hazcrecerunsue-o/)

## Abrir los archivos del proyecto

El punto de entrada que conecta todas las secciones del sitio es:

### [Ver `index.html` en el repositorio](./index.html)

Desde la página principal se puede navegar hacia:

- El bosque y seguimiento de cirugías.
- La comunidad de personas donantes.
- El flujo de donativos.
- La sección para empresas.

## Vistas principales

- [`index.html`](./index.html) — página principal y flujo de donativos.
- [`crecimiento.html`](./crecimiento.html) — bosque de los sueños.
- [`comunidad.html`](./comunidad.html) — comunidad de personas donantes.
- [`empresas.html`](./empresas.html) — alianzas y participación empresarial.

## Estructura

- `assets/` — imágenes, SVG, videos y favicons utilizados por el sitio.
- `css/` — estilos generales y estilos de la sección para empresas.
- `js/` — interacciones, datos dinámicos y footer compartido.

El proyecto utiliza HTML, CSS y JavaScript vanilla, por lo que no requiere instalación de dependencias.
